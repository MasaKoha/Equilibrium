# 研究目的と対象ゲーム

## 1. 研究目的

### 1.1 背景

デジタルカードゲームのバランス調整は、カード単体の性能だけでなく、カード同士の組み合わせ、デッキ構成、プレイヤーの戦略、ランダム性、対戦環境など、多数の要素によって左右される。

カードの追加や調整によって、開発者が想定していない強力な組み合わせが発生する可能性もある。

人間によるプレイテストだけで、膨大なカードの組み合わせを網羅的に検証することは困難である。

そこで、AIによる自動対戦と統計解析を利用し、カードゲームのバランスを定量的に評価する仕組みを研究・開発する。

### 1.2 研究の目的

本研究では、以下を実現する。

1. AI同士の大量対戦によるデッキ性能の評価
2. カード単体の性能と勝率への影響の評価
3. カード間のシナジーとコンボの検出
4. デッキの安定性と特定カード依存率の評価
5. ランダム効果の期待値と変動幅の評価
6. レアリティ・入手難度・デッキ構築コストの評価
7. カードTier表・デッキTier表の自動生成
8. カード調整による対戦環境の変化の分析
9. 開発者が評価結果を確認できる可視化環境の構築

### 1.3 最終的に解決したい問題

開発者が次の質問に、定量的な根拠を持って回答できる状態を目指す。

- このカードは強すぎないか？
- このカードが強い理由は何か？
- どのデッキで特に強いのか？
- 特定のカードを引けないと勝てないデッキになっていないか？
- デッキ事故やランダム性による負けが過剰ではないか？
- 安価なデッキでも高価なデッキに勝てるか？
- 特定の色や戦略だけが環境を支配していないか？
- 新カード追加で既存デッキのTierはどう変化するか？
- カード性能を変更した場合、環境は改善するか？
- 評価結果はどの程度信頼できるか？

### 1.4 開発方針

当面は自社カードゲームへの導入を最優先とする。

他社ゲームへの汎用対応、外部SDK、商用サービス化などは初期開発の必須要件としない。

ただし、ゲームルール、シミュレーション、AI、統計分析、可視化の責務を分離し、将来的な拡張を妨げない設計とする。

## 2. 対象ゲームの基本仕様

### 2.1 ゲーム概要

| 項目 | 内容 |
|---|---|
| プラットフォーム | デジタル専用 |
| 対戦形式 | 1vs1 |
| 属性 | 白・青・黒・赤・緑・無色 |
| 色のコンセプト | Magic: The Gatheringを基本的に踏襲 |
| カウンター呪文 | なし |
| ランダム要素 | ランダムターゲット等を含む |
| レアリティ | 採用予定 |
| デッキ構築コスト | 評価対象とする |

### 2.2 属性コンセプト

白

- 防御
- 回復
- 小型ユニットの横展開
- 全体強化
- 秩序や協調を表現する能力

青

- ドロー
- 手札操作
- バウンス
- 行動制限
- テンポ・コントロール

MTG型のカウンター呪文は採用しない。

黒

- クリーチャー除去
- 手札破壊
- 墓地利用
- 生け贄
- ライフを代償とする能力

赤

- 直接ダメージ
- 速攻
- 短期決戦
- ランダム効果
- 爆発的な攻撃性能

緑

- 大型ユニット
- リソース加速
- ユニット強化
- 成長
- 戦闘を通じた盤面制圧

無色

- 汎用カード
- 装備・補助
- 特定色に依存しない能力

各色の具体的な能力範囲は今後調整する。

### 2.3 未確定仕様

以下は現時点では確定しない。

- マナシステム
- デッキ枚数
- 同名カードの投入上限
- カードの種類
- 各カード効果の詳細
- レアリティ区分
- カード取得・生成方式
- ランク戦等の対戦環境

研究用シミュレーターは、これらのルールが変更される可能性を考慮して設計する。
