# 評価の全体像・カード単体・シナジー

## 3. 評価システムの全体像

評価システムは、以下の分野に分割する。

1. カード単体評価
2. カード間シナジー評価
3. デッキ全体評価
4. 安定性・依存性評価
5. 経済性・レアリティ評価
6. 対戦環境評価
7. Tier評価
8. AI評価品質
9. 統計的信頼性

各分野の評価結果を独立して保存する。

複数指標を無条件で単一の総合スコアに統合しない。

特に、競技的な強さとゲームバランスの健全性は別々に評価する。

## 4. 評価における基本変数

| 記号 | 意味 |
|---|---|
| D | 評価対象デッキ |
| C | 評価対象カード |
| E | 対戦環境 |
| A | 対戦AI |
| R | ゲームルール・カードデータのバージョン |
| S | 乱数シード |
| N | 試合数 |
| T | 評価対象ターン |

すべての評価には、実験条件を紐づける。

同じカードやデッキでも、対戦AIや対戦環境が異なれば評価結果は変化する。

## 5. カード単体評価

### 5.1 基礎性能

カードの基本的な性能を評価する。

主な指標：

- 使用コスト
- 攻撃・防御性能
- 効果量
- リソース獲得量
- 対象範囲
- 効果の発動条件
- 効果の持続時間
- 同コスト帯との性能差
- 同じ役割のカードとの性能差

基本性能の単純比較だけで強弱を決定しない。

カードの役割やデッキ内の用途を考慮する。

### 5.2 カードの勝率貢献度

カードCを含むデッキDと、カードCを代替カードに差し替えたデッキを比較する。

計算式

`Contribution(C,D) = WR(D) - WR(D_without_C)`

ここで "D_without_C" は、カードCを指定した代替カードに置換した合法デッキを指す。

評価では以下を固定する。

- 対戦相手
- 対戦AI
- 先攻後攻比率
- 対戦環境
- ゲームバージョン

必要に応じて共通乱数を利用する。

代替カードによって結果が変わるため、比較対象も記録する。

### 5.3 カード取得時の性能

次の条件で評価する。

- 初手に存在
- 序盤に取得
- 中盤に取得
- 終盤に取得
- 試合終了まで未取得

条件別勝率を算出する。

ただし、取得時勝率はカードの因果的な貢献を直接表すものではない。

試合時間や取得機会の違いによるバイアスを考慮する。

### 5.4 使用可能率

カードを取得した際、使用条件を満たしている割合を測定する。

例：

- 必要なリソースが不足している
- 対象が存在しない
- 発動条件を満たさない
- 使用可能だが戦略的な価値が低い

「ルール上使用可能」と「有効なプレイとして使用可能」を分離する。

### 5.5 ランダム効果評価

同一盤面でランダム効果を複数回解決し、結果の確率分布を評価する。

主要指標：

- 期待値
- 分散
- 標準偏差
- 最小値
- 最大値
- 5%点
- 95%点
- 有効対象への命中確率
- 上振れ率
- 下振れ率

期待値

`E[X] = Σ (結果の値 × 発生確率)`

分散

`Var(X) = E[(X - E[X])²]`

同じ効果でも盤面により分布が変化するため、盤面条件別に評価する。

## 6. カード間シナジー評価

### 6.1 目的

カード単体では強くなくても、複数のカードを組み合わせることで強力になる場合がある。

そのため、カード間の相互作用を評価する。

### 6.2 2枚のシナジー

カードA・Bについて、次の4条件を用意する。

1. AとBが両方存在
2. Aのみ存在
3. Bのみ存在
4. AもBも存在しない

計算式

`Synergy(A,B) = WR_AB - WR_A - WR_B + WR_0`

これは、指定した基準デッキ・代替カード・対戦環境における相互作用の指標となる。

単独では弱いカードでも、組み合わせによって強力になる現象を検出する。

### 6.3 コンボ評価

主な指標：

- コンボ成立率
- コンボ成立までの平均ターン
- コンボ成立時勝率
- コンボ未成立時勝率
- 必要カード枚数
- コンボ妨害率
- 成立条件の厳しさ
- コンボの代替手段

### 6.4 想定外コンボの探索

将来的には、デッキ構築AIによってカードの組み合わせを自動探索する。

高勝率の組み合わせだけでなく、無限ループ、早期決着、一方的な盤面形成なども検出対象とする。
