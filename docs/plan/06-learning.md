# 学習する科目とロードマップ

## 17. 学習すべき情報工学の科目

### 17.1 Sランク：初期開発に必須

学習内容：

- 条件付き確率
- ベイズの定理
- 確率分布
- 期待値・分散
- 二項分布
- 超幾何分布
- モンテカルロ法

実習：

カードの取得確率とランダム効果の結果分布を計算する。

数理統計学

学習内容：

- 推定
- 信頼区間
- 仮説検定
- ブートストラップ法
- 回帰分析
- 多重比較

実験計画法

学習内容：

- 対照実験
- ランダム化
- ブロック化
- 交絡因子
- 効果量
- 検出力分析

実習：

人工知能

学習内容：

- ゲーム木探索
- Minimax
- Alpha-Beta
- Expectimax
- MCTS
- 不完全情報ゲーム
- 盤面評価関数

実習：

対戦AIを作成する。

ソフトウェア工学

学習内容：

- 状態管理
- 責務分離
- 状態遷移
- 不変条件
- テスト
- 再現性

実習：

C#で正規ゲームコアを構築する。

## 18. 学習ロードマップ

1か月目：確率論・統計学

学習内容：

- 確率分布
- 期待値
- 分散
- 信頼区間
- カード取得確率

成果物：

カード取得確率とランダム効果の分析プログラム。

2か月目：シミュレーション工学

学習内容：

- 状態遷移
- 乱数管理
- ゲームロジック
- テスト

成果物：

C#による最小限のHeadlessゲームエンジン。

3か月目：対戦AI

学習内容：

- ルールベースAI
- 盤面評価関数
- 基本的な探索アルゴリズム

成果物：

AI同士の自動対戦システム。

4か月目：実験計画と評価

学習内容：

- 比較実験
- 信頼区間
- キーカード依存率
- カード差し替え評価

成果物：

カード性能・デッキ性能の評価レポート。

5か月目：最適化とTier表

学習内容：

- デッキ探索
- 制約付き最適化
- Tier算出
- データ分析

成果物：

カードTier・デッキTier・予算別ランキング。

6か月目：高速化・可視化

学習内容：

- CPU並列処理
- プロファイリング
- Unityでの可視化
- リプレイ

成果物：

自社プロダクトで試験運用可能な研究版。

※6か月は週6〜8時間程度の学習・研究を仮定した目安であり、実用版の完成時期を保証するものではない。
